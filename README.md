# 简记 · jianji

一个本地优先的 Android 记账应用：安装即用，不需要注册或登录，默认数据只存在你自己的手机里。

## 功能

- [x] 记账 —— 每一笔花销和收入，都记下来
- [x] 统计 —— 清楚知道钱去了哪里
- [x] 分类管理 —— 按自己的习惯理账
- [x] 应用锁 —— 这本账只有你能看
- [x] 导入导出 —— 账目带得走，也带得回
- [x] 云备份 —— 自部署服务器，可选，默认关闭
- [ ] 多端同步 —— 换设备，还是同一本账
- [ ] AI 接口 —— 让 AI 帮你读账、算账

## 使用与安装

这是 Android 应用（Android 8.0 及以上），下载安装包直接安装即可，不需要准备任何运行环境。

安装包发布后会出现在 [Releases](https://github.com/Fhesk-Will/jianji/releases/latest)，点进去下载最新的 APK。首次安装时若系统提示，需要在设置里允许「安装未知来源应用」。

安装完成后打开就能记账，无需注册。默认所有数据只保存在本机、不上传任何服务器；开启自部署云同步后，账本会自动备份到你的服务器（也可以手动「立即同步」），随时可以从服务器的历史版本恢复整本账，换机不丢数据。卸载应用会清除本机数据，服务器上的历史版本不受影响；未使用云同步时，建议先在「设置」里把账目导出成表格留一份。

桌面小部件：不同品牌手机入口略有差异，一般是长按桌面空白处（或长按应用图标）→ 小部件/插件，找到「简记」拖到桌面。

## 自建云同步与 AI 查询（可选）

仓库里的 [`sync/`](sync/) 是配套的自部署服务：把账本备份到你自己的服务器（版本历史 + 云端恢复 + 误删熔断 + 滚动保留），并提供只读查询接口给 AI 助手用。服务端用 Docker + PostgreSQL 运行；App 默认关闭同步，想用时在「设置」里填入自己部署的服务地址和密钥即可，不需要改代码。
